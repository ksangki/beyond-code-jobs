# 코드 너머의 직업들

> GPU 위에서 일하는 사람들

"코드 너머의 시대"(2026)의 후속작이자 *코드 너머의* 시리즈 두 번째 책입니다. PC·인터넷·모바일이 세 번 반복한 패턴 위에서, AI 인프라 다음에 자라는 5개 새 직업의 도감과 현직자의 전환 지도를 담았습니다.

## 읽기

- **웹 버전**: [GitHub Pages에서 읽기](https://ksangki.github.io/beyond-code-jobs/)
- **오프닝 영상**: [60초 모션그래픽](https://ksangki.github.io/beyond-code-jobs/media/opening.mp4) · 웹 버전 첫 화면에도 실려 있다
- **발표 자료**: [1시간 발표 슬라이드](https://ksangki.github.io/beyond-code-jobs/presentation/) · 원천 `deck/slides.py`
- **EPUB**: [`코드-너머의-직업들-v1.1.8.epub`](docs/epub/코드-너머의-직업들-v1.1.8.epub) 다운로드
- **판 이력**: v1.1.2 (2026-11-01): 문체 점검, AI 문체 패턴 169곳 정리, 내용·수치 변경 없음
- **판 이력**: v1.1.3 (2026-11-01): 내용 정합성 정리, 10·13·14장 수치·출처 표기, 간주곡 장 참조, 8장 일반화 범위
- **판 이력**: v1.1.4 (2026-11-02): 7장 수진의 회사 소재를 13장 사례와 같은 한국으로 맞춤, 웹 책 표 가로 넘침 보정
- **판 이력**: v1.1.5 (2026-11-07): 문체 2차 점검(한국어 표현 지침), 248곳 정리, 내용·수치 변경 없음
- **판 이력**: v1.1.6 (2026-11-07): 참고문헌 Threads 링크가 링크로 보이도록 고침, 내용·수치 변경 없음
- **판 이력**: v1.1.7 (2026-11-07): 참고문헌 주소를 링크로 바꾸고 접근 확인, 3곳 주소 갱신, 내용·수치 변경 없음
- **판 이력**: v1.1.8 (2026-11-07): 열리지 않는 참고문헌 한 항목을 뺌, 본문 변경 없음
- **판 이력**: v1.1.9 (2026-11-07): 전작 표기 오류(출판사) 바로잡고 사실과 다른 감사 문장 삭제

## 목차

| PART | 장 | 제목 |
|------|---|------|
| | 프롤로그 | 풍경이 닮아 있다: 2010년의 모바일, 2025년의 AI |
| **PART 1** | 1장 | 반도체는 늘 먼저 갔다: PC·인터넷·모바일의 같은 순서 |
| 인프라가 먼저 가고, 사람이 따라온다 | 2장 | 시차는 점점 짧아진다, 그리고 AI는 더 빠르다 |
| | 3장 | 우리는 지금 어디쯤 와 있나: Nvidia 신고가, SaaS 회귀, 채용 시장의 신호 |
| **PART 2** | 4장 | GPU와 데이터센터가 가능하게 한 것들: 길이·속도·비용 |
| AI 위에서 일이 돌아가는 방식 | 5장 | 에이전트가 일을 한다는 것: 도구가 아니라 동료에 가까운 |
| | 6장 | 새로운 비즈니스 모델: 시트당 과금에서 결과물 과금까지 |
| **PART 3** | 7장 | AI Product Manager: 모델을 제품으로 만드는 사람 |
| 새 직업의 해부 | 8장 | Forward Deployed Engineer: 고객 현장에서 모델을 다듬는 사람 |
| | 9장 | Applied AI Engineer: 백엔드·풀스택 개발자의 자연스러운 다음 자리 |
| | 10장 | Agent 운영자 / AgentOps: 이 책의 시그니처 직군 |
| | 11장 | Eval Engineer · AI Reliability: 품질을 측정하고 책임지는 사람 |
| **막간** | | 정직한 한 페이지: 우리가 틀릴 수 있는 9가지 |
| **PART 4** | 12장 | 한국 시장에서 이 흐름은 어떻게 다른가: 대기업·스타트업·SI의 자리 |
| 어디서 어디로: 현직자의 전환 지도 | 13장 | 어디서 어디로: 현직별 전환 경로와 사례 |
| | 14장 | 다음 5년을 준비하는 90일 플랜: 자가진단부터 행동까지 |

## 핵심 메시지

> "반도체는 먼저 갔고, 사람은 따라간다. 그리고 사람의 자리는 새로 만들어진다."

> "GPU와 데이터센터는 이미 깔렸습니다. 다음은 그 위에서 일하는 사람들의 차례입니다."

> "두려움에서 일정표로."

## 누가 읽으면 좋은가

- **1순위**: 현직 개발자·PM의 커리어 전환 가이드: 백엔드, 풀스택, PM, SI 컨설턴트, SRE, QA, 데이터 엔지니어
- **2순위**: 시대를 읽고 싶은 일반 직장인과 기획자

## 전작과의 관계

| | 코드 너머의 시대 (전작) | 코드 너머의 직업들 (본서) |
|---|---|---|
| 다루는 층 | 사람의 **내면** (역량·태도) | 사람의 **외형** (직업·자리) |
| 질문 | 어떤 사람으로 살아남을까 | 어떤 자리에서 살아남을까 |
